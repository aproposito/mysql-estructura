# MySQL - Estructura de Bases de Datos

Ejercicios de diseño y modelado de bases de datos relacionales con MySQL Workbench, generados como parte del Sprint 02 del bootcamp FullStack PHP.

## Ejercicios

### 1. Óptica Culo de Botella
Base de datos para la gestión de una óptica. Incluye tablas de clientes, proveedores, gafas y ventas.

- `Optica_culo_botella.sql` — Script de creación de la base de datos
- `Optica_culo_botella.svg` — Diagrama entidad-relación

### 2. Pizzeria Mario
Base de datos para la gestión de una pizzería con pedidos a domicilio. Incluye tablas de clientes, pedidos, productos y repartidores.

- `pizzeria_mario.sql` — Script de creación de la base de datos
- `pizzeria_mario.png` — Diagrama entidad-relación

### 3. MiTube
Base de datos para una plataforma de vídeos al estilo YouTube. Incluye tablas de usuarios, vídeos, canales, tags y suscripciones.

- `mitube.sql` — Script de creación de la base de datos
- `mitube.png` — Diagrama entidad-relación

## Tecnologías

- MySQL 8.x
- MySQL Workbench (Forward Engineering)
